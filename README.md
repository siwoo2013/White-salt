# White_salt_V6 — 페이지별 적용 확인판

각 메뉴에서 고유 콘텐츠가 곧바로 표시됩니다. GitHub 저장소 최상위에 압축 해제한 파일과 폴더를 업로드하세요.

- 회사소개: 회사정보, 조직도, 연혁, 신안 이미지
- 스마트팜: 시설형 스마트 생산 이미지
- 생산공정: 노지 염수에서 하우스 결정화까지 공정 이미지
- 제품소개: 250g, 1kg, 20kg, 스틱 제품, 페이지 하단 YouTube 영상
- 품질관리: 품질관리 이미지
- B2B·수출: 계약·악수 이미지
- 고객센터와 푸터: 주소, 대표, 연락처, 허가증 번호, 사업자번호

이미지 파일은 images/에 있으며 제품, 슬라이드 기존 파일 유지. 파일 교체는 같은 이름 사용.

이 버전에서는 요청한 핵심 페이지 콘텐츠가 data/pages.json의 비동기 로딩에 의존하지 않습니다.

연혁 문구는 제공된 이미지의 내용을 옮긴 것으로, 게시 전에 최종 표기를 확인해 주세요.
