# V17 게시판 등록 가이드

- `공지/002_홈페이지오픈.txt` : 공지게시판에 새 글 등록. 텍스트 파일 내용이 본문.
- `자료/003_회사소개서.txt` : 자료실에 새 글 등록.
- `자료/003_회사소개서.pdf` : 같은 번호 `003_`를 가진 자료실 게시글에 첨부파일로 연결.
- 번호는 `001_`, `002_`, `003_`처럼 사용. **번호가 클수록 상단**에 표시됩니다. 공지/자료 폴더 간 번호 중복은 허용합니다.
- `.txt` 인코딩은 UTF-8 권장. 파일명에서 첫 번째 `_` 뒤의 글자가 게시글 제목이 됩니다. 메모장 저장 시 UTF-8로 저장하세요.
- 순번이 없는 텍스트 파일은 게시글로 등록하지 않습니다.
- GitHub에 업로드/커밋하면 Render 빌드 과정(`node scripts/build-site.js`)에서 게시판 목록을 자동 생성합니다. 목록 JSON은 수정할 필요가 없습니다.
- PDF/DOCX/XLSX/ZIP 파일 첨부 지원(자료 폴더). 같은 번호의 첨부파일 여러 개도 지원합니다.
- `공지·자료실` 메뉴는 모바일 좌우 스와이프 순서에도 포함됩니다. English 버전에서 게시글 내용은 원문 한국어 그대로 표시됩니다.
- 신규 게시글 반영이 안 되면 Render Blueprint의 `buildCommand`가 `node scripts/build-site.js`인지 확인하세요.
